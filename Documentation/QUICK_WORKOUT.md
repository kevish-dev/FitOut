# Quick and planned workouts

Both launch the shared [focused workout experience](FOCUSED_WORKOUT.md).
The screen shows one ordered exercise and current set, system exercise artwork,
editable inputs, clearly labelled set/workout/rest clocks, and a large primary
action. Laps are no longer part of the workout UI or Live Activity controls.

[Input recall](WORKOUT_INPUT_RECALL.md) supplies previous weights and reps while
preserving manual edits and prescriptions. Completion remains explicit. The new
execution metadata extends the existing JSON supplement; historical SwiftData
schemas and old recorded sessions remain readable.
